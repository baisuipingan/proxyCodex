使用教程

Codex 连接中转站详细教程

下载客户端后，按下面的流程接入 MiloRouter。CC Switch 会负责导入配置，不需要手动编辑 Codex 配置文件。

7 个步骤
接入要点先在 MiloRouter 创建 API Key，并在创建过程中选择模型；然后从密钥页面导入 CC Switch，启动 Codex 后即可测试。

01 · 注册账号

注册并登录 MiloRouter

打开 MiloRouter 中转站，使用常用邮箱注册并完成验证。

  1. 填写邮箱和密码，密码至少 6 位。
  2. 获取邮箱验证码并完成注册。
  3. 登录后进入仪表盘，确认账户状态。

不要向他人提供邮箱验证码或登录密码。

02 · 购买额度

购买并兑换额度

从控制台进入“充值小铺”，购买额度后把兑换码兑换到账户余额。

  1. 选择需要的美元额度并完成支付。
  2. 复制购买成功页面显示的兑换码。
  3. 回到控制台的“兑换”页面提交兑换码。
  4. 刷新仪表盘，确认余额已经增加。

兑换码区分大小写，每个兑换码只能使用一次；不要公开兑换码或订单信息。

03 · 创建密钥

创建 API Key 并选择模型

进入“API 密钥”页面创建一个专用密钥。模型在创建密钥的流程中直接选择，不需要另外配置模型广场。

  1. 点击“创建密钥”，填写用途名称，例如 codex-laptop。
  2. 选择要使用的模型或对应分组。
  3. 按需设置额度、速率、IP 和有效期限制。
  4. 保存后立即复制 API Key，并妥善保管。

不要把完整 API Key 发到聊天、截图或公开仓库；建议为不同设备分别创建密钥。

04 · 导入 CC Switch

从密钥页面导入配置

在刚创建的密钥操作区点击“导入到 CCS”，允许浏览器打开 CC Switch。

  1. 回到 API 密钥列表，找到目标密钥。
  2. 点击“导入到 CCS”，在浏览器提示中允许打开应用。
  3. CC Switch 打开后，确认 MiloRouter 供应商已经出现在 Codex 配置区域。

如果提示 CC Switch 未安装或协议未注册，请先安装可信版本，再重新点击导入。

05 · 启动并测试

在 CC Switch 中确认配置后启动 Codex

导入成功后，在 CC Switch 中确认供应商和模型，保存并启用配置，然后直接启动 Codex。

  1. 确认 MiloRouter 地址、密钥和模型已经填入。
  2. 确认配置已保存并处于启用状态。
  3. 启动 Codex，新建 task，发送一条简短请求。
  4. 收到回复后即可开始正常使用。

不需要手动修改 config.toml 或 auth.json；CC Switch 导入完成后直接启动 Codex 即可。

06 · 查看记录

在使用记录确认调用

请求成功后回到 MiloRouter 控制台，打开“使用记录”，确认这次调用已经被记录。

  • 模型和请求是否对应预期配置。
  • 本次调用使用的 Token 数量。
  • 实际扣费、响应时间和请求状态。

07 · 常见排查

无法使用时按顺序检查

遇到未授权、余额不足、模型不可用或连接超时，可以依次检查：

  1. 账户余额是否充足。
  2. API Key 是否启用、过期，或触发额度、速率、IP 限制。
  3. CC Switch 中的模型是否与创建密钥时的选择一致。
  4. 渠道状态和网络连接是否正常。
  5. 完全退出 Codex 后重新打开，再创建新 task。

联系客服时不要发送完整密钥；提供密钥名称、模型 ID、系统、发生时间和遮盖后的日志即可。

模型、价格、额度商品和客户端版本可能调整，请以 MiloRouter 控制台和本页下载列表当前显示内容为准。
